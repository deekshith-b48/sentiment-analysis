# 😃 PyTorch Sentiment Analysis

This repo contains tutorials covering understanding and implementing sequence classification models using [PyTorch](https://github.com/pytorch/pytorch), with Python 3.9. Specifically, we'll train models to perform sentiment analysis on text data. 📚

## 📋 Requirements

- Python 3.9
- PyTorch
- TorchText

## 🚀 Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/deekshith-b48/sentiment-analysis.git
    cd sentiment-analysis
    ```

2. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Run the training script:
    ```bash
    python train.py
    ```

## 📁 Project Structure

- `train.py`: Script to train the sentiment analysis model.
- `model.py`: Defines the architecture of the model.
- `data.py`: Data processing and loading.
- `utils.py`: Utility functions.
